# Лабораторная работа 2.1

## Логические группы, на которые разделены тесты
1. Проверка того, что алгоритм находит пару.
2. Проверка случая, когда к цели ведет несколько разных пар.
3. Проверка работы с отрицательными числами.
4. Проверка возврата None, когда пары не существует, в массивах с отрицательными числами.
5. Проверка работы на большом массиве с повторяющимися элементами.
6. Пустой массив, массив из одного элемента.

## Ошибки, которые способен обнаружить каждый тест

* test_middle_elements находит ошибки в логике перебора.
* test_first_and_last_elements находит ошибку выхода за пределы массива, если алгоритм неправильно считает индексы.
* test_multiple_valid_pairs выявляет ошибку, при которой алгоритм выдает исключение, если находит более одной пары.
* test_mixed_signs проверяет, что алгоритм корректно работает с операциями сложения положительных и отрицательных чисел.
* test_all_negative находит ошибки, если алгоритм работал изначально лишь с положительными числами.
* test_no_solution_negative выполняет проверку, что функция не выдает 0 или пустой список, когда нет решения.
* test_large_array находит ошибки при работе с повторяющимися элементами.
* test_empty_and_single проверяет условия для крайних случаев.


## Вывод
Таким образом, описанный набор тестов позволяет изучить не только случаи, при которых легко найти ошибку, но и граничные условия.  
Использование отрицательных и положительных чисел проверяет работу логики.  
Тест с парами гарантирует, что функция возвращает 1 пару, без возвращения всех. Тест с большим массивом проверяет эффективность алгоритма, а также корректность работы с дубликатами. 
В совокупности эти тесты дают право утверждать, что функция соответствует требованиям.
