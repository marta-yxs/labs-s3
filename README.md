#Лабораторная работа 2

##Условие задачи
На вход подается массив целых чисел nums и число target. Необходимо найти в массиве два таких числа, сумма которых равна target, и вернуть их индексы.

##Решение
Поиск двух индексов, сумма элементов которых равна target, методом полного перебора. При отсутствии решения возвращается пустой список.

def add(nums, target):
    for a in range(len(nums)):
        for b in range(a + 1, len(nums)):
            if nums[a] + nums[b] == target:
                return [a, b]
    return []
